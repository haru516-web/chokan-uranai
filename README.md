# 潮環占い（仮名）

人生と今日を「海」で読む、新しい占い体系の設計サイト。

生年月日と下の名前の画数から決まる「名札」（季節＋数値＋特別マーカー）を中心に、
内側の円「海況」（12ステージ・4年周期）と外側の円「海流」（12種・12年周期）の
組み合わせで、今日の進み方から一生の流れまでを読みます。

## サイトの構成

- **はじめに** — 潮環占いとは何か、名札の読み方、使い方
- **今日の海** — 今朝の海と帰りの海（その日で実際に計算される日々の読み）
- **名札** — 名札計算機と読み解き
- **海の暦** — 海況12ステージ・海流12種・皇紀起点ルールなどの解説
- **海図** — 生まれ年から未来までの流れの年表、月別海況、組み合わせランキング
- **相性** — 二人の海（簡易デモ）
- **設計ノート** — 決定事項と未決定事項の記録
