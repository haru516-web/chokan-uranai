# 潮環占い

人生と今日を「海」で読む、iOSとWeb向けのアプリです。四季と深さで16の海の住人に出会い、年の海流、四か月の海況、今日の月を重ねて読みます。

## 起動

Node.js 22.13以上を使います。

```sh
npm ci
npm run web
```

- **Web配信用**　`npm run export:web` で `dist/` に出力します。Webサーバーの公開ルートから配信してください。
- **iPhone**　`npm start` で開発サーバーを起動し、このExpo SDKに対応するExpo Goから開きます。MacのiOSシミュレータは `npm run ios`。インストール用アプリを作る場合は、MacのXcodeかEAS BuildでiOSの署名とビルドを行います。iOSのバンドルIDは `jp.haru516.chokanuranai` です。

## できること

| 画面 | 内容 |
|---|---|
| 今日 | 五段階の運勢と160名札の順位、ひと言と一手、年・四か月・日の重ね読み |
| 問い | 名前や生年月日を入れずに読める24の問い、自分の潮札での読み直し |
| 海図 | 過去12年の海流と海況、運勢の円環グラフ、潮環の暦 |
| 図鑑 | 季節と深さで分けた16の海の住人、検索、お気に入り、創作神話「見られなかった海」 |
| 航海帳 | 自分の潮札、保存した問い、出来事と当時・今の受け取り方、二人の海 |

潮札では、季節の神の画像、今日の順位、運勢の円環グラフを確認できます。潮札の入力を保存するかは選べます。航海帳・お気に入り・読了状態はiOSではアプリ内、Webでは使用中のブラウザに保存されます。

## 計算と素材

- 名札の計算は旧版を引き継ぎます。季節4 × 深さ10 ×「−」の有無 × Aの有無で160種。図鑑の16種は、深さ10を浅瀬・沿岸・沖合・深海にまとめたものです。
- 海流は12年、海況は4年で巡ります。日付と月の読みは日本時間を基準にし、月の値は正午で評価します。
- 旧版の静的試作は `index.html`、当時の設計メモは `DESIGN.md` にあります。現行版の開発入口は `index.ts` です。
- 画像の内訳と制作プロンプトは [assets/ARTWORK.md](assets/ARTWORK.md) にあります。

漢字の画数は KANJIDIC2（© Electronic Dictionary Research and Development Group、[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)）から作ったデータを使用しています。画数データ部分は同じ条件で利用できます。月の計算は Jean Meeus『Astronomical Algorithms』の主要項を使用しています。
