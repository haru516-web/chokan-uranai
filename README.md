# 潮環占い（仮名）

人生と今日を「海」で読む占い。生年月日と下の名前から決まる「あなたのタイプ（名札）」に、
今日・今月・今年の海を重ねて、いまの調子を **順位と一言（大漁・順風・凪・荒波・轟沈）** で伝えます。

`index.html` をブラウザで開くだけで動きます（単一ファイル・外部依存なし）。
ローカルで確認する場合は `node .claude/serve.js` → http://localhost:8765

## 使い方（4つのメニュー）

| メニュー | 答える問い |
|---|---|
| 今日 | 今日どう過ごす？ 今日の順位・一言・一手、年×月×日の重ね読み、これからの7日 |
| 流れ | 今年・今月はどんな流れ？ 12種類の海流・海況の比較（過去と先を同数）、回せる輪 |
| 順位 | みんなの順位は？ 全160タイプの今日の順位（上位・下位5位はSNSでも公開する想定） |
| あなた | 私はどんなタイプ？ タイプの意味と比較の図、入力の変更、仕組み・読み物などの資料 |

初回は「入力 → あなたのタイプ → 今年・今月・今日 → 今日」の一本道です。
入力は保存しません（リロードすると最初の画面に戻ります）。

## 仕組み（核）

- **名札**（変わらない）: 季節4（生年月日）× 深さ10（名前の画数）× 「−」（生年月日の桁）× A（二進数）＝160タイプ
- **3つの海**（暦で全員共通）: 年＝海流12種（12年周期）／月＝海況12種（4ヶ月ごと・4年周期）／日＝月の形と月の距離。皇紀（西暦＋660）の起点で計算
- **点数**: 名札と今日の海の組み合わせを、海況点・季節×月の形・深さ×月の距離・季節の拠点・季節×海流・「−」・A・日の波で採点し、160タイプを順位づけ
- **月の形と月の距離**: 天文計算（Meeus）による本物の値。互いに連動しない独立した材料（月の形＝29.53日周期、月の距離＝27.55日周期）
- **乱数なし**: 同じ日付なら、誰が開いても同じ結果。日付は日本時間の正午で評価
- 計算の全容はアプリ内の「あなた → 仕組み」に載せています

## 既知の限界

- 漢字の画数は辞書（KANJIDIC2）の現代字形の画数を自動で使う。辞書にない異体字（例：髙）は手入力
- かなの画数は、濁点2画・半濁点1画として数えている
- 潮の実際の高さ（場所ごとの観測データ）は使っていない
- 点数の重みは設計案で、人生データでの検証はしていない
