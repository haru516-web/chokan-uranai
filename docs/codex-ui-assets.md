# Codex への依頼：iOSアプリ用の UI 画像素材（まとめ）

アプリの部品（カード・ボタン・入力欄・ナビなど）を、画像素材で「iOSアプリらしく」する。画像を `assets/ui/` に、**下の表のファイル名どおり**に置く。コード側の受け皿は用意済み。届いた画像は、Claude 側で、`src/artFiles.ts` に足してつなぐ。

## なぜ、形ごとに分けるか
部品の縦横比が、ばらばら（細長い行〜縦長のカード）。1枚の画像を、全体に引き伸ばすと、角の飾りが歪む。そこで、**形ごとに別の画像**を用意し、アプリが部品の形を見て、合うものを選ぶ（選ぶ仕組みは Claude 側で作る）。

## 共通ルール
- WebP、角は透明、3x（下の大きさ）。各500KB以下が目安。
- 文字は入れない（文字は、アプリ側で重ねる）。
- 同じ種類の画像は、形が違っても、世界観・色・縁の太さ・角の飾りの大きさを揃える（角の飾りは、どの形でも同じ大きさ。引き伸ばした形に見えないこと）。
- 色や雰囲気は、`DESIGN.md`、`assets/art/` の既存の絵、納品済みの4枚に合わせる。
- 中央は無地に近くする（上に文字や絵が載る）。

## 受け取ったあとの手順（Claude 側）
1. `src/artFiles.ts` の `uiFiles` に、届いた画像の `require` を足す。
2. 形（縦横比）で画像を選ぶ仕組みを、`src/cardGlow.ts` と `src/ui-assets.css` に作る。
3. 画面で、歪みがないことを確認する。
