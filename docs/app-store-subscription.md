# 有料版（月額サブスク）の準備手順

アプリ側のコードは入っています（`src/billing.ts`）。動かすには、App Store Connect で次を用意し、アプリを**新しくビルド**する必要があります（expo-iap は、Expo Go では動きません）。

## 1. App Store Connect で用意するもの
1. 「契約・税金・口座情報」で、**有料App契約**を結ぶ（口座・税の情報が必要）。
2. アプリの「サブスクリプション」で、**サブスクリプショングループ**を作る（例：潮環占い プレミアム）。
3. グループの中に、**自動更新サブスクリプション**を作る。
   - 製品ID：`jp.chokanuranai.app.premium.monthly`（`src/web/native.ts` の `PRODUCT_ID` と同じにする）
   - 期間：1か月　／　価格：450円（税込の表示は、Appleが国ごとに決める）
   - 表示名・説明（日本語）、審査用のスクリーンショット（申込み画面）を入れる。
4. アプリの審査情報に、**プライバシーポリシーのURL**を入れる（ネット上のアドレスが必要）。利用規約は、アプリ内の画面で足りるが、App Store の説明欄にも載せておくと安心。
5. 動作確認用に、「ユーザーとアクセス」→ **Sandboxテスター**を作る。

## 2. 動作確認（実機）
- 開発ビルドを実機に入れ、Sandboxテスターで申込み・復元・解約を試す。
- 確認すること：無料のとき鍵がかかる／申込みで開く／アプリを再起動しても開いたまま／「購入を復元する」で戻る／解約後、期間の終わりに鍵がかかる。

## 3. 仕組みのメモ
- 有料かどうかは、端末の中で、Appleの署名つきの購入の記録を見て決める（サーバーなし）。
- 通信できないときは、前回の確認結果（7日以内）を使う。
- ブラウザーでの確認用：`?mockbilling=free` または `?mockbilling=paid` を付けて開くと、疑似の課金で画面を確認できる（開発時のみ）。
